# 🛠️ appSatTech - Sistema de Gestão de Chamados Técnicos

O **appSatTech** é uma aplicação web desenvolvida em **ASP.NET Core MVC** projetada para gerenciar e acompanhar solicitações de assistência técnica em tempo real.
